# ABOVE ATLAS — Logo Usage

The identity is a single mark: the letter A with its crossbar lifted
off and floating above the apex. The thing that belongs inside the
structure has moved above it. That's the program, in a letterform.

---

## THE FILES

| File | Use it for |
|---|---|
| `above-atlas-mark.svg` | The mark alone. Cap front, sleeve, favicon, avatar, sign-off, anywhere the name is already present |
| `above-atlas-mark-reversed.svg` | Same, cream, for dark grounds |
| `above-atlas-horizontal.svg` | Default lockup. Site header, letterhead, email signature, slide corner |
| `above-atlas-stacked.svg` | Vertical spaces. Tee front, poster, program cover, IG profile |
| `above-atlas-icon.svg` | 512x512 app icon and social avatar. Rounded square, mark knocked out |
| `mockups/` | Cap mockups in three colorways, for vendor conversations only |

## THE MARK — WHAT NOT TO BREAK

**The gap is the idea.** The space between the bar and the apex is
what makes it read as *above* rather than as a printing error. Never
close it, never shrink it, never let a designer "tighten it up."

**The bar is half the width of the A's footprint.** Wider and it
becomes a roof. Narrower and it becomes an accent mark.

**The apex is a hard miter.** Never round it. `stroke-miterlimit` is
set to 6 in every file — if you rebuild the mark in another program,
match it or the point flattens.

---

## RULES

**Clear space.** On all four sides, leave space equal to the height
of the floating bar. Nothing enters it.

**Minimum size.**
- Mark alone: 0.4 in / 40 px
- Horizontal lockup: 1.25 in / 130 px
- Stacked lockup: 1 in / 110 px

**One ink. Always.** No gradients, no two-color versions, no drop
shadows, no outline added around the whole thing.

**Never:**
- Close or shrink the gap
- Round the apex
- Rotate or shear the mark
- Put a circle, shield, or badge around it
- Set the wordmark in a different face than the lockup
- Use the NeuroChiro orange #E8561A anywhere in Above Atlas

---

## COLOR

- Ink: `#101010` — near-black. Not pure black
- Approved alternate ink: `#12213A` (existing navy)
- Light ground: `#F2EDE4` cream, or a sand blank
